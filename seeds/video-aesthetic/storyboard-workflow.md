# 配音文案 → 镜头剧本 · 生产规范

**职责边界**：本专家只做逐句画面设计。划段、时间轴、块级路线全部上游已定——**消费，不生产**。

## 第 0 步 · 输入契约（缺一即拒绝开工）

| 输入 | 形态 | 校验 |
|---|---|---|
| 定稿稿件 | md | 与索引 source_sha256 一致 |
| 段落索引 | json | 身份三元组（schema_version + source_sha256 + audio_sha256）；哈希不符即拒绝，提示上游重算 |
| 已确认大段表 | md | 划段/路线/分工已过用户审批 |
| 频道设计文档 | 知识卡 `channel-design-<频道>` | 无则先走投喂→确认→建文档 |

任一缺失：**明确说出缺什么，停**。禁止估算时间轴、禁止跳过校验、禁止"先写个大概"。

## 第 1 步 · 帧号引用规范

- 一律引用**绝对帧号**（60fps）；秒只作显示列，由采样换算（48000Hz，800 采样 = 1 帧）
- **`[F0, Fend)` 半开区间**：段终帧号属于下一段，本段不含
- **词点锚定**：从字级时间戳取触发词，写法「『整』字起（F106，词点 85200/48000=1.775s）」——变化必须挂在具体词上，不挂"大约第几秒"
- **切点纪律**：视觉切换只落在块界或段间静音缝（缝宽 = 下段 start − 上段 end，引用前先算，个别为 0 或 −1）；**不得切进正在朗读的句子**
- 末段终点 ≠ 末块终点（尾部静音），内容帧以末段终点为准

## 第 2 步 · 段头六件套（每个 D 块开头）

1. **画面增量**：口播说什么 vs 画面补什么。判据 = 盖住画面，观众损失了什么（见 shot-semantics）
2. **主角对象**：本块唯一主角，开场即在位；从上块接棒，向下块交棒
3. **对标片**：有无同类已确认片；新类型须写明两个验证点
4. **景别与相机**：基准景别（如全景 Full Shot）、每次变化用的镜头语言（Dolly Out / Rack Focus / Dutch Angle ≤5° 等）、z 三分层（远/主/前景各 z 值）
5. **节奏曲线**：快段↔慢段各标帧区间
6. **密度**：按频道设计文档口径核算（单位时间画面变化次数），写明本块目标值

## 第 3 步 · S 行表格（逐句）

| 配音（句/语义组，真实词点） | 画面上发生的变化 | 镜头与视线 | 停稳/阅读 |
|---|---|---|---|

- 每句一行；帧区间来自索引段落，触发词来自字级时间戳
- 「画面」列写**变化**不写状态——观众这一句看到什么在变，怎么变
- 「停稳」列：每次变化后跟的静止区间（写帧区间 + 秒），让观众消化

## 第 4 步 · 段尾三件

- **上屏文字白名单**：本块允许上屏的全部文字（如仅 4 个对象名）；其余一律不上屏。附**不写清单**（口播句复读、提示语、banner 角标）
- **高潮帧**：指定一帧为「它就是 XX」时刻，给足静止（≥1s），期间不叠加任何其他动作
- **接棒**：本块结束时画面状态，原样交给下块

## 四条实战纪律（违反即返工）

1. **停稳**：每次变化后必须有停稳区间，不允许连续变化不落地
2. **气口全静**：全静气口区间内无动作、无新对象、无入画
3. **开场前 3 秒不引入新对象**：第一眼是「有个东西正被指着」，不是片头、不是标题卡
4. **主角唯一**：一个块一个主角对象，不换场景、不清屏重搭（除非大段表另有路线）

## 第 5 步 · 交付顺序（不可倒）

镜头剧本全文 → **交用户审** → 通过后写成片预演（见 film-preview 卡）→ 再交审。
用户审是唯一放行，**禁止自评通过**。

统一看 `combo-rules` 卡。风格依据 = **频道设计文档**（不是候选体系的 7 卡）。
