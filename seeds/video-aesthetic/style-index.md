## 三、体系构成策略

**向「可高效生产的画风」倾斜**（福特黑车原则：设计被生产线约束）。

- 制作全由 AI Agent 完成：`mg`（Remotion 组件）完全可控 = 骨干；`gen-video` 可控性中等 = B-roll
- 体系库构成：扁平矢量 / MG 动态图形类占多数；写实 3D / 实拍类谨慎
- 目标数量：4–6 个槽位（讲解型 / 数据型 / 故事型 / 概念演示型 / 宣传冲击型），先槽位后材料
- 上限 15 体系

## 四、投喂流程（收到网址 / 仓库 / 素材堆时）

任务是**蒸馏成候选体系卡**，不是逐条总结。

1. **分诊**：粗看材料判断画风倾向。判据：两堆代表帧并排，普通人一眼能说「不一样」就分堆。宁可少分，不要错分。
2. **取样**：网址抓正文 + **截图**；视频**必须 ffmpeg 抽帧**（6–9 帧）再逐帧 read_image——审美的真载体是画面，文字只是旁证；GitHub 只读 README + 截图/demo。**材料若附 AI 提示词，提取生成关键词**（画风/材质/光照词，图与词冲突以图为准）。
3. **蒸馏**：每堆按 `style-card-schema` 出 7 卡。
4. **存档**：写入 `视频风格素材库/体系库/<体系id>/`（cards/ + frames/ + index-row.md），**不写入专家知识库**；更新本卡目录表。
5. **建档**：用户确认后按 `channel-design-guide` 写频道设计文档（此时才进知识库）。

**外部 AI 产出**：一律先落 `视频风格素材库/待验收/<体系id>/`，验收后移入 `体系库/`。**验收用工具**：`node 视频风格素材库/工具/验收体系.mjs <体系目录|单文件.md>`（自动查 11 项：七卡齐全/hex/画风单选/关键帧/禁忌/词表/禁用词），WARN 项人工确认。**一个风格开一个对话**，多风格同批必互相污染。交接文档：`视频风格素材库/蒸馏交接包/README.md`（含对话框模式与分诊两阶段流程）；首批用 `首批最小验证-提示词.md`。

**限制**：一次 ≤8 个网址；超量分多轮。

## 五、使用流程（接到剧本任务时）

按 `storyboard-workflow` 第 0 步核输入契约 → 读**频道设计文档**（无则先走投喂→确认→建档）→ 逐块逐句写剧本。

## 六、蒸馏验收标准

- 色板固定 hex；动效有曲线类型与时长区间；画风档位单选（禁 3D 卡通与 3D 写实并存）
- ≥2 张代表作关键帧，路径有效；禁忌 ≥3 条「这不是 XX 当…」
- -layout / -motion 左列用 shot-semantics 的表意功能词
- 10 秒样例文案过一遍：7 卡能完整生成这段画面吗
- **最终验收人是用户**：交用户判断「像不像」，专家不得自评通过
