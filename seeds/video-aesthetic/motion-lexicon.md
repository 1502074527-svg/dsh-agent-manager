# 镜头与动效 · 词汇表（封闭）

**用途**：与 `shot-semantics`（表意功能词表）配对——表意功能回答「为什么动」，本表回答「怎么动」。三处消费：
1. 体系卡 `-motion` 的「镜头原型」列
2. 剧本「镜头与视线」列
3. `素材库/动效模式库/` 的模式条目

## A. 运镜原语（画框级，15 词）

| 词条 | 参数维度 | 表意倾向 | 注意 |
|---|---|---|---|
| push-in 推近 | 幅度% / 时长 / 曲线 | 强调、加压 | 幅度 8–12% 画宽为宜 |
| pull-out 拉远 | 同上 | 揭示全貌、收束 | 拉远后需停稳 |
| pan 横摇 | 方向 / 幅度 | 跟随、扫视 | 机位不动，只转朝向；主体勿出画 |
| tilt 纵摇 | 方向 / 幅度 | 揭示高度/纵深 | 机位不动，只转朝向 |
| dolly 移动 | 进/出 / 幅度 | 空间穿行 | 与 zoom 区分：dolly 有透视变化 |
| **crane 升降** | 方向 / 幅度 / 时长 | 揭示规模、升腾 | 机位整体升降；含 pedestal 升降台、jib 摇臂 |
| rack-focus 转焦 | 焦点 A→B / 停留 | 注意力转移 | A 需清晰停 ≥0.5s 再交 B |
| parallax 视差 | 层数 / 速度比 | 空间层次 | 远层慢、近层快 |
| orbit 环绕 | 角度 | 展示立体物 | 扁平体系慎用 |
| whip 甩切 | 方向 | 高能转场 | 全片 ≤2 次 |
| dutch 倾斜 | 角度 | 失稳、不安 | **静态**倾角 ≤5°；倾角在变用 roll |
| **roll 滚转** | 角度变化 / 时长 | 失稳、旋转感 | dutch 的连续版（倾角持续变化） |
| zoom 变焦 | 幅度 | 压缩/扩张感 | 透视不变，与 dolly 区分 |
| **handheld 手持感** | 扰动幅度 / 频率 | 纪实、紧张 | 持续微扰，非一次性抖动 |
| **shake 冲击抖动** | 幅度 / 衰减时长 | 撞击、冲击 | 一次性衰减，典型 0.3–0.5s 归零 |

> **归并**：pedestal 升降台 / jib 摇臂 → `crane`；spin 快速自转 → `rotate`（元素级，高速变体）；dolly zoom（眩晕变焦）→ `dolly` + `zoom` 反向叠加，不单列。

## B. 元素动效原语（元素级，17 词）

fade（淡入出）· slide（滑入，标方向）· rise（上浮）· scale（缩放）· grow（生长：柱/线/形）· morph（形变）· wipe（擦除）· mask-reveal（遮罩揭示）· count-up（数字滚动）· typewriter（逐字出现）· stagger（错峰，标间隔）· pop（弹入）· drop（落下）· draw-on（描边绘制）· liquid（液态）· **rotate（自转：绕自身轴，非 orbit）** · **smear（拖影：作画/高速运动的残影帧）**

可加修饰组合：`count-up-elastic`、`wipe-same-block`、`rotate-loop`（持续自转循环）。

## C. 转场类型

cut 硬切 · fade 叠化 · wipe 擦除 · push 推移 · match-cut 匹配剪辑 · morph 形变转场
**警告**：fade 叠化是最常被滥用的转场，多数体系卡应直接禁用或限量。

## D. 物理参数词

anticipation 预备 · follow-through 跟随 · overlap 重叠 · overshoot 过冲 · **settle 停稳**（剧本「停稳」列即此）· secondary 次级动作

## E. 非运镜词（不入本表，引用时写全名）

这些是**拍摄载体、视点选择或时间处理**，不是镜头动作——**不造词根**，剧本里直接写全名并注明：

| 词 | 中文 | 为什么不入表 |
|---|---|---|
| fpv | 穿越机视角 | 拍摄载体；实际动作是 push-in / dolly 的连续前冲 |
| pov | 主观视角 | 视点选择，不是运动 |
| loop | 循环 | 时间结构（素材循环播放） |
| cycle | 周期 | 节奏属性 |
| slow-motion | 慢动作 | 时间处理 |
| speed-ramp | 变速 | 时间处理（曲线在时间轴上重映射） |
| time-lapse | 延时 | 时间处理；表意落点 = 时间流逝 |
| freeze-frame | 停帧 | 时间处理 |

## 纪律

- 用词条必给参数：时长（帧或秒）+ 曲线（cubic-bezier）+ 幅度
- **不自造同义词**：「缓入浮现」不合法，用 `rise` + ease 参数表达
- 需要新词条：先提案进本表，再使用
- 本表与《蒸馏交接包/动效与运镜蒸馏.md》第 6 节必须一致，改一处同步另一处
