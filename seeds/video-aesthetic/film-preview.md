# 成片预演 · 写作规范

成片预演在**镜头剧本通过用户审之后**写，是进入制作前的最后一道审。目的：用户不看任何表格，只读预演就能在脑中连播全片。

## 写法（按观看顺序逐块）

每块回答五问：

1. **开场结构**：这一块的钩子/结构是什么（如"三次不同坏法 → 揭示真因"）
2. **这一段要完成什么**：观众的认知从哪走到哪（"从前 3 秒认出场景 → 把人从'模型不行'引到'规矩没写进'"）
3. **第一眼看到**：不是片头不是标题卡，具体到"一张奶油色工作台上的文档，一行被选中，光标在闪"
4. **接着发生**：编号列出变化（1. 2. 3.），每次写"观众看到什么在变"，不写制作手段
5. **最后停在哪里**：收束状态 + 交给下块什么

**语言纪律**：用观众视角的具体动作，不用镜头术语（Dolly/Rack Focus 留在剧本里）；保留帧区间与全静气口标注，方便用户对时间。

## 叙事原则（写预演与剧本共用）

- 钩子四起法：反直觉 / 冲突数字 / 悬念前置（先给结果再讲为什么）/ 痛点场景
- 信息密度高—低交替；每 20–30s 一次换气（低密度句/过渡句）
- 收尾两种闭环：呼应开头的钩子 / 明确行动号召
- 禁止：突然结束、收尾引入新概念、预演里出现制作参数

## 审

预演交用户。判定标准只有一条：**用户说"能在脑中播"**。过了才进设计图与制作；不过则回剧本改，不直接改预演。
