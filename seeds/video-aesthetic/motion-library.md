## 二、条目形态

每条含：类型 / 表意功能（封闭词表）/ 时长 / 曲线（**带判定依据的帧间位移数据**）/ 预备 / 跟随 / 过冲 / 结构 / 组合错峰 / 适用画风 / 出处（材料号+帧区间）。

**引用时必须连同出处一起引用**，只抄参数不写出处 = 丢失可追溯性。

## 三、调用纪律

1. **建档时**：按题材挑适用条目，吸收进设计文档「运动系统」章（带出处）
2. **剧本时**：不查本库，只读频道设计文档
3. **术语**：条目名用 `motion-lexicon` 词根；库内复合名（如 `rise-anticipation-launch`）可作为风格专属模式名保留
4. **缺口**：38 项「未观察到」已如实记录，不得当作已确认参数

## 四、已知词表缺口

条目里出现的 `rotate / smear / crane / pedestal / jib / roll / handheld / shake / fpv / pov / spin / loop / cycle` 等词根**不在** `motion-lexicon` 表内。这些是真实观察到的动作，但词表尚未扩充——引用时保留原词并标注「词表待扩」，不要自造同义词替换。
