# 组合合法性（单一来源，其他卡不得复写本规则）

**组合的定义**：全片锁定 1 个主体系，允许从其他体系借 **≤1 个元素** 做点缀。判定目标：这一次借用会不会破坏主体系的识别。

## 一、层级可借表

| 层 | 可借性 | 理由 |
|---|---|---|
| 画风与材质（-medium） | ❌ 绝对不可 | 身份层，混入即换人 |
| 字体（-type） | ❌ 不可 | 最强风格识别符 |
| 构图语法（-layout） | ❌ 不可 | 空间秩序，混则散 |
| 色板（-color） | ⚠️ 只可借**单个点缀色** | 整套配色比例不可借 |
| 动势/镜头（-motion） | ✅ 可借 | 时间维度，感知为节奏，不与静态识别冲突 |
| 物理惯性（-physics） | ⚠️ 可借**参数**，不可借规则 | 参数可局部调 |

## 二、四个判定测试

**T1 · 遮挡测试**（判层级）
遮住借来的元素，画面还认得出主体系吗？认得 → 合法；认不得 → 非法。

**T2 · 三帧识别测试**（判串味）
抽片头/中段/片尾 3 帧，判断「这是哪个体系」。3 帧答案一致 → 未串味；有分歧 → 必改。

**T3 · 占比测试**（判点缀）
借来元素的面积 ≤10% **且** 时长 ≤10%。超过 → 不是点缀，是第二体系。

**T4 · 替换测试**（判该不该借）
换成主体系自己的对应元素，画面更好？更好 → 本不该借，回退。

## 三、三档结论

```
✅ 合法
  只借动势或惯性参数；占比 ≤10%；
  只出现在情绪句/过渡句；T1-T4 全过

⚠️ 灰区（须用户确认）
  借动势但占比 10–20%；用在数据句/观点句；同时借 2 个元素

❌ 非法（直接返工）
  借字体/构图/画风；借整套色板；同时借 ≥3 个；
  T2 三帧识别分歧
```

## 四、为什么数据句/观点句不许借

这两类承担信息传递，观众需要最清晰的读取。借来的动势引入陌生节奏，增加认知负荷。情绪句/过渡句本来就要「换气」，外来节奏反而提神。

## 五、风格间借用的另一面：禁止向下污染

主体系定了之后，下游所有产出（含生成 prompt、图片风格词）必须用主体系的词汇。给 `gen-video` 写 prompt 时，画风描述只准用主体系 `-medium` 卡里的词。
