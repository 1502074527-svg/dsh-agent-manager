# 风格体系卡 · Schema（每个风格 7 张卡）

命名：`style-<体系id>-<部位>`，体系 id 用 kebab-case（如 `style-swiss-motion`）。

7 卡合计 ≥2 个关键帧本地路径。**每张卡正文按下面模板填空。**

## 卡 1 · -medium（画风与材质）

```markdown
---
name: style-<id>-medium
description: <体系名>的画风与材质：判断该风格用什么视觉媒介、质感如何时加载
---
# <体系名> · 画风与材质
画风档位（**只能选一个**，选完全体系不许混）：
- [ ] 扁平矢量 / [ ] MG 动态图形 / [ ] 3D 渲染（须细分：3D 卡通 / 3D 写实 / 3D 低多边形）
- [ ] 手绘涂鸦 / [ ] 拼贴剪纸 / [ ] 实拍合成 / [ ] 生成式 / [ ] 像素复古 / [ ] 线框蓝图
质感：表面____（哑光/渐变）· 边缘____（硬边/描边）· 光影____（无投影/45°长投影）· 纹理____
**生成关键词**（从参考材料的 AI 提示词提取，可复用风格词，英文为主）：____（如 flat vector, muted earth palette, paper grain, 2.5D parallax）
混合允许度：默认不允许
对生视频工具的约束：该画风下 gen-video 只能/不得____（如：只作 B-roll）
禁忌：____
关键帧：/路径/f01.jpg
```

## 蒸馏纪律

- 每个字段**具体可执行**（hex、px、秒、cubic-bezier），形容词一律重写
- 没把握写「未观察到，待补」，不编造
- **动效/物理字段证据不足时写「待动效蒸馏补充」**——均匀抽帧看不到运动，动效另有专门蒸馏（见《蒸馏交接包/动效与运镜蒸馏.md》），不要凭单帧猜
- 画风档位**必须单选**；一个体系内不得同时出现 3D 卡通与 3D 写实
- -layout 与 -motion 的左列**必须用 shot-semantics 的表意功能词**，保证跨体系可比
- -motion 的镜头原型**必须用 motion-lexicon 词条**
- 组合规则**不写进体系卡**，统一看 combo-rules 卡
- 蒸馏完更新 style-index 目录表
