# 使用说明

> **关于名字**：面板里仍然叫「智能体」（实际使用不变）；插件市场里按 `owner/repo` 显示为 `1502074527-svg/dsh-custom-subagents`（仓库与包名已从 `dsh-agent-manager` 改名）。都是同一个插件，面板里仍叫「智能体」。

## 1. 它解决什么问题

DSH 里「主智能体」负责主持对话。很多重复工作适合固化成一个专门角色：固定的岗位说明、固定的工具、固定的判断标准。这个插件让你：

- 把角色写成 Markdown 文件（一份定义 = 角色 + 提示词 + 工具 + 模型 + 判断标准）；
- 用面板可视化地新建、修改、启用、开会话；
- 从 12 份起步模板里挑一个改，而不是从空白开始；
- 给角色配图标、知识卡、风格，让它「一眼认得、叫得动」。

角色保存后会注册成 DSH 预设，之后一句话就能把它叫出来干活。

## 2. 数据放在哪

| 内容 | 路径 |
| --- | --- |
| 用户级角色（所有项目可用） | `~/.dsh/agents/<name>.md`（`DSH_HOME` 可覆盖根目录） |
| 项目级角色（只在该项目） | `<项目>/.dsh/agents/<name>.md` |
| 启停与信任策略 | `~/.dsh/agent-manager/projects.json` |
| 知识卡 | `~/.dsh/agent-manager/knowledge/<角色>/<卡片>.md` |
| 风格库 | `~/.dsh/agent-manager/styles/` |

角色就是普通 Markdown，可以直接用编辑器改、可以进 git；面板只是它的可视化壳。

## 3. 五个屏幕

| 屏幕 | 你能做什么 |
| --- | --- |
| 首页 | 搜索、按用户级/项目级筛选、看卡片；下方是五个领域起点 |
| 详情 | 看头像、一句话、元信息、工具与判断标准；开会话 / 编辑 / 启停 / 删除；知识库页签 |
| 编辑器 | 01 角色 / 02 能力 / 03 模型 / 04 图标 / 05 高级；底部保存 |
| 模板库 | 12 份模板按五组归组；从编辑器进来时高亮「当前起点」 |
| 风格库 | 就地弹层编辑，保存后写回本机 |

导航只有一条返回链：详情 → 首页、编辑器 → 详情/首页、模板库 → 来处。Esc 逐层退出（输入框 → 内层弹层 → 屏幕）。

## 4. 新建一个角色的最快路径

1. 首页点一个领域卡（例如「技术」）——会预填提示词、工具与判断标准，并从卡面写明的那份模板开始；
2. 补齐两个必填：
   - 「它叫什么」：显示名，例如「接口评审」；
   - 「什么时候叫它」：主智能体只凭这句话决定要不要调用，写清触发场景；
3. 需要的话调 02 能力的工具勾选（改过之后换模板不再覆盖你的选择）；
4. 保存。

想从空白开始：首页「新建智能体」或最下方虚线卡。

## 5. 字段速查

| 字段 | 位置 | 说明 |
| --- | --- | --- |
| 它叫什么 | 01 角色 | 显示名；同时推导内部代号（小写字母/数字/连字符，保存后不可改） |
| 什么时候叫它 | 01 角色 | **必填**，主智能体的调用依据 |
| 岗位说明 | 01 角色 | 提示词正文：流程、纪律、交付标准 |
| 工具 | 02 能力 | 按领域自动勾；手动改过就以你的为准 |
| 模型 / 推理强度 | 03 模型 | 留空继承全局默认 |
| 图标 | 04 图标 | 30 款，单行横向滚动 |
| 内部代号 / 作用域 | 05 高级 | 作用域决定用户级还是项目级 |
| 默认风格 | 05 高级 | 模板没声明 `style` 时不显示 |
| 判断标准 | 05 高级 | 可核对的数字规则、必须项、禁止项 |

## 6. 模板、领域与起点

- 12 份模板分五组：视觉（视频美学/平面品牌/UIUX）、技术（代码审查/架构设计/数据分析）、内容（文案/写作研究/翻译）、产品运营（产品需求/运营增长）、学习（学习教练）。
- 领域卡会取该组的**第一份模板**，卡面写明「从「X」开始 · 共 N 个」；点进去后编辑器左栏底部有「起点：X · 换」，可以换另一份，换起点只替换提示词、工具、判断标准与模型，名字/触发场景/作用域/图标保留。
- 模板声明了 `modules` 的，编辑器只显示对应页面（例如不带风格的模板不显示「默认风格」）。

## 7. 图标

30 款 160px 透明 PNG，来自同一套形象（小鲸鱼）。

- **新建角色时，初始头像会从这 30 款里随机挑一款**——不会再是光秃秃的几何徽记；
- 想换：编辑器 04 图标页，点任意一款即可，选中后同步到卡片、详情、会话头部徽章与侧栏；
- 想回到几何徽记：点「恢复默认徽记」（头像字段清空，回退到按名字生成的图形）；
- 编辑已有角色时，头像保持原样，不会重新随机。

图标区是单行横向滚动，选中后不收起，方便连续对比。

## 8. 知识卡

每个角色有自己的知识库，两种建法：

- **丢材料自动建库**：粘贴文本或填网址，按「什么时候用这张卡」拆成卡片；
- **手动新建**：自己写标题、适用场景、正文。

知识卡靠「什么时候用这张卡」被检索，所以那句话要写使用场景（不是内容概括）。已有卡片的「卡片标识（文件名）」保存后不可改——改名等于新建，旧文件会留着。

## 9. 启停与信任

- 启停是**按项目**保存在本机的策略，不写进定义文件；
- 项目级角色默认停用，要先信任这个项目或在详情里启用；
- 项目里有同名文件但未被信任时，卡片会标「项目里有同名定义，未信任，未生效」；
- 新建项目级角色后，提示条直接给「启用它」。

## 10. 在对话里叫它

- 面板详情「开新会话」；
- 对话头部徽章菜单选一个（键盘 ↑↓ 选择、Esc 关闭并还焦）。

单次问答模式（`llm`）的角色不建会话，用 `/agent` 或让主智能体按需调用。

## 11. 键盘与可访问性

| 操作 | 行为 |
| --- | --- |
| `/` | 首页聚焦搜索框 |
| ↑↓←→ | 卡片网格移动焦点（按真实列数与分组边界） |
| Tab | 整个卡片网格只占一个站位 |
| Esc | 输入框只退出输入；弹层先退弹层；再退一层屏幕 |
| 回车/空格 | 打开卡片 |

弹层打开会聚焦层内首个可操作项、Tab 在层内循环、关闭还焦、背景 `inert`。

## 12. 并发与安全

- 保存时比对文件修改时间：文件在你打开之后被别处改过，会拒绝覆盖并给「读取最新版（保留我的修改）」；
- 删除会二次确认，并说明连带删除多少张知识卡；
- 同名覆盖在新建时会被拦截；编辑时只允许改自己那份。

## 13. 常见问题

**问：改模板后工具又变回去了？**
答：只有「没手动改过工具」时换模板才会覆盖；你在 02 能力里动过任何一项，之后换起点不会碰工具。

**问：卡片显示「已停用」，开不了会话？**
答：项目级默认停用；填好项目路径后点详情里的「启用」，或在提示条点「启用它」。

**问：能在别的项目用吗？**
答：用户级角色可以；项目级只在该项目目录下出现。作用域可在 05 高级里改，保存时会移动文件。

**问：面板里叫「智能体」，市场里叫「自定义子智能体」，是同一个吗？**
答：是同一个。市场改名只为和几个同名仓库区分。

## 14. 已知边界

- 面板宽度自适应 420–1180px，更窄时卡片转单列、编辑器导航折到顶部；
- 弹层是整窗遮罩，真实面板比窗口窄时会盖住侧栏区域；
- 说明文档与界面文案以中文为主，英文只覆盖侧栏元信息。

## 15. 与同名/近名插件的区别

| 项目 | 它做什么 | 与本插件的关系 |
| --- | --- | --- |
| `dogbotowo-oss/dsh-agent-manager` | 停止并移除子智能体 / Agent Teams 成员 | 不同功能：它管「运行中的实例」，本插件管「角色定义」 |
| `qingli-sketch/dsh-preset-agent-manager` | 侧栏面板 + `preset_agent_dispatch`，带插件白名单与子会话隔离 | 同赛道：它押调度与权限隔离，本插件押定义编辑 + 模板/知识卡/风格 |
| `litestartup-com/dsh-agent-manager` | 个人/小团队 AI agent 中台 | 不同层次：平台而非面板 |

一句话：**本插件是「角色定义 + 可视化编辑」，不替你做多实例调度。**
